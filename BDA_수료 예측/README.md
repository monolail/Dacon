# 데이콘 x BDA 제 2회 학습자 수료 예측 AI 경진대회

이 프로젝트는 **BDA(Big Data Association) 11기 학회원 최종 과제**의 일환으로 진행된 **'학습자 수료 예측 및 이탈 방지 전략 수립'** 분석 프로젝트입니다. 학회원들의 활동 데이터를 바탕으로 수료 여부를 예측하고, 데이터 기반의 인사이트를 통해 학회 운영 개선 전략을 제안합니다.

## 1. 프로젝트 개요
- **배경**: 조별 활동은 협업 학습과 네트워크 형성의 핵심이나, 일부 인원의 중도 이탈은 조 전체의 사기와 성과에 부정적인 영향을 미침.
- **목적**: 
  - 학습자 이탈 현황을 정량적으로 파악.
  - 이탈에 영향을 미치는 주요 요인을 분석하여 수료율을 높이기 위한 운영 전략 도출.
  - '이탈 방지 안전망' 구축을 통한 학회 가치 증대.

## 2. 데이터 분석 결과 요약
- **전체 수료율**: 약 **29.8%** (이탈률 70.2%로 매우 높은 편).
- **신분별 분석**: 대학원생(Grad Student) 그룹의 이탈률이 가장 높게 나타남.
- **참여 형태**: 오프라인 참여 희망자 사이에서 역설적으로 높은 이탈자가 발생 (이동 거리, 시간 소요 등 물리적 장벽 원인 추정).
- **주요 요인**: 초기 활동 데이터(class 참여도 등)가 실제 수료와 밀접하게 연관됨.

## 3. 주요 분석 프로세스
### 1) 데이터 전처리 (Preprocessing)
- **결측치 처리**: 수치형 데이터는 `Median`으로 채우고, 범주형 데이터는 'Missing'이라는 새로운 범주로 처리하여 정보 손실 방지.
- **피처 엔지니어링 (Feature Engineering)**:
  - `total_class_count`: 수강 신청한 클래스 수 합계를 통한 학습 의지 수량화.
  - `whyBDA_len`, `what_to_gain_len`: 지원 동기 텍스트 길이를 통한 참여 열의도 추출.
  - `job_group`: 유사 성격의 신분을 그룹화하여 노이즈 감소.
- **스케일링**: `StandardScaler`를 통한 수치 데이터 정규화.

### 2) 모델링 (Modeling)
- **사용 모델**: `CatBoostClassifier`
  - **선정 이유**: 범주형 변수가 많고 결측치가 빈번한 데이터 특성에 강하며, 과적합(Overfitting) 방지에 효과적임.
- **검증 방법**: Stratified K-Fold (5-fold) 교차 검증을 통해 모델의 일반화 성능 확보.
- **최적화**: 단순히 확률 0.5를 기준으로 분류하지 않고, 검증 데이터에서 **F1-score가 최대화되는 최적의 임계값(Threshold)**을 찾아 적용.

## 4. 최종 제안 및 인사이트
1. **대학원생 맞춤형 리텐션 전략**: 대학원생의 이탈은 의지 부족이 아닌 '환경적 요인(연구실 일정 등)'이 크므로, 유연한 커리큘럼(녹화본 학습 비중 확대 등) 제공 필요.
2. **오프라인 선호자 관리**: 오프라인 활동에 대한 기대가 실망으로 이어지지 않도록 지역별 거점 소모임 매칭이나 초기 오프라인 밋업(Meet-up) 배치를 통한 결속력 강화.
3. **초기 이탈 징후 포착**: 활동 초기의 데이터로 수료 가능성이 낮은 인원을 조기에 식별하여 운영진 차원의 집중 관리 프로세스 가동.
