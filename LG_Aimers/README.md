# KBO 투수 제구력 예측 모델

## 1. 프로젝트 개요
- **최종 순위:** 649위
- **대회 목표:** KBO 투수의 다양한 상황과 과거 통계 데이터를 기반으로 다음 투구의 제구 성공(스트라이크, 인플레이 타구 등) 여부를 정확히 예측.
- **핵심 과제:** 2019~2023년(인간 심판)의 과거 데이터와 2024년(ABS, 로봇 심판 도입)의 구조적 변화 차이를 극복하고, 2025년 시즌(Test 셋)의 제구력을 정확히 예측할 수 있는 일반화 모델 구축.

## 2. 변수 설계 및 피처 엔지니어링 (Feature Engineering)
과거 데이터에 과도하게 의존하는 선수 개인 ID(`pitcher_id`) 타겟 인코딩의 과적합 문제를 해결하기 위해, 투수 본연의 능력과 상황을 정량화한 순수 세이버메트릭스(Sabermetrics) 기반 파생 변수를 설계했습니다.

### 2.1. 세이버메트릭스 파생 변수
- **`count_adv` (볼카운트 유불리):** `strikes_before - balls_before`
  현재 볼카운트 상황에서 투수와 타자 중 누가 더 심리적 압박감을 느끼고 있는지 정량화했습니다.
- **`pitcher_cmd` (투수의 제구력 비율):** `asof_pitcher_strike_rate / (asof_pitcher_ball_rate + 0.001)`
  단순한 누적 성공률이 아닌, 투구한 볼 대비 스트라이크의 비율을 계산하여 투수의 실질적인 커맨드(Command) 능력을 측정했습니다.
- **`pitcher_fastball_stuff` (투수의 직구 구위):** `asof_pitcher_fastball_rate * asof_pitcher_success_rate`
  직구 구사 비율과 전체 성공률을 결합하여, 직구를 중심으로 카운트를 잡아낼 수 있는 투수의 구위를 수치화했습니다.

### 2.2. 트랙맨(Trackman) 데이터 안정화
- 2019~2021년 등 과거 트랙맨 데이터의 결측치로 인한 시계열 노이즈를 방지하기 위해, 투수별 전체 기간의 평균을 낸 '글로벌 트랙맨 지표'로 병합하여 안정적인 피처를 구성했습니다.

### 2.3. 팀 단위 전술 범주화
- **`pitcher_team_id`, `batter_team_id`:** 특정 선수의 과거 성적에 과적합되는 것을 막는 대신, 팀 단위로 나타나는 투수 교체 기조 및 타석 전략의 차이를 모델이 학습할 수 있도록 범주형(Categorical) 변수로 포함시켰습니다.

## 3. 모델링 및 도메인 적응 (Domain Adaptation)
단순 예측을 넘어, 대회의 핵심 평가 지표인 Brier Score를 최적화하고 ABS 시대에 맞는 모델을 구성하고자 다음과 같은 접근을 시도했습니다.

### 3.1. ABS 룰 도메인 가중치 적용
- 2025년 시즌을 정확히 예측하기 위해, 유일하게 ABS 룰이 적용된 **2024년 데이터에 가중치(Sample Weight) 3배를 부여**하여 모델 학습을 진행했습니다. 이를 통해 모델 트리가 과거 5년 치의 인간 심판 존보다 2024년 로봇 심판 존의 오차를 우선적으로 줄이도록 강제(Domain Adaptation)했습니다.

### 3.2. 정밀 확률 보정 (Isotonic Regression)
- 트리 모델의 예측 확률값이 쏠리는 현상을 방지하기 위해, 2024년 검증 데이터를 바탕으로 `Isotonic Regression`을 적합시켜 산출된 예측 확률의 신뢰도를 교정했습니다.

### 3.3. 극한의 분산 제거 (Mega Ensemble)
- 트리 기반의 강력한 3대장 알고리즘인 **LightGBM, XGBoost, CatBoost**를 모두 사용했습니다.
- 하이퍼파라미터를 극한으로 조율하여 `n_estimators=1500`, `learning_rate=0.01`로 깊고 촘촘하게 학습시켰습니다.
- 모델당 10개의 Random Seed를 부여하여 **총 30개의 정밀 트리 모델**을 생성하고, 다수결(Soft Voting)을 통해 앙상블을 수행함으로써 일반화 성능을 극대화하고 오차 분산을 소멸시켰습니다.
